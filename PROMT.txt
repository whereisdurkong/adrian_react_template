## Day/night rules (most important)
My theme is switched by data-theme="dark" on the <html> element. Colors are CSS variables in src/styles/variables.css. Dark values are in the :root[data-theme="dark"] block.

1. Never hardcode colors. No #fff, #111, rgb(), or named colors in CSS or in SVG attributes. Always use var(--name).
2. Use these existing variables:
   - Surfaces: --bg, --panel-bg, --surface, --surface-dark, --surface-dark-2
   - Text: --text-primary, --text-secondary, --text-muted (--text-on-dark and --text-on-dark-secondary are for always-dark areas)
   - Lines: --border, --border-dark
   - Brand and data: --accent, --accent-dim, --accent-soft, --purple, --purple-soft, --purple-dark, --green, --green-soft, --red, --red-soft, --blue, --blue-soft
   - Shadows: --shadow-sm, --shadow-md, --shadow-lg
   - Shape and motion: --radius-sm/md/lg/xl/full, --font, --mono, --ease, --duration
3. If I ask for a color that doesn't exist, add a named variable in BOTH places: the light value in :root and a dark value in :root[data-theme="dark"]. Show me those lines as a separate snippet for variables.css. Do not use a raw color in the page CSS.
4. Dark values must stay readable: text contrast at least 4.5:1, and "soft" backgrounds should be translucent (rgba) in dark mode.
5. Text on the lime --accent is always dark (#111 via a variable or a fixed dark token), in both themes.
6. Custom shapes and SVG: style them with CSS classes using fill: var(--x) and stroke: var(--x), or use currentColor. Gradients use stop-color: var(--x). Shadows use my shadow variables.
7. Canvas or chart libraries that need real color values: read them with getComputedStyle(document.documentElement).getPropertyValue("--name") and re-read when data-theme changes, using a MutationObserver (the same way my Palette page does).
8. Don't add your own theme toggle or theme logic. The navbar toggle and useTheme hook already exist.
